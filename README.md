# JEV Emoji

맥 메뉴 막대에 사는 작은 이모지 추천 앱입니다.
글을 쓰다가 **⌥⌘E**(Option+Command+E)를 누르면, 커서 주변 문장을 읽어 TypeSafe의 **JEV** 모델에게 어울리는 이모지 10개를 물어보고, 고른 이모지를 원래 입력칸에 바로 넣어 줍니다.

> **개발자 미리보기**입니다. Apple Silicon Mac과 macOS 14 이상에서만 동작하고, Apple 공증을 받지 않았습니다.

---

## 어떻게 동작하나요

1. 메뉴 막대에 웃는 얼굴 아이콘이 생깁니다. Dock에는 나타나지 않습니다.
2. 글을 쓰다가 ⌥⌘E를 누릅니다. 문장 읽기는 **macOS에 입력칸 정보(커서 위치와 글 내용)를 알려 주는 앱**에서만 됩니다.
   이 정보를 알려 주지 않는 앱(일부 웹 브라우저, Electron 앱 등)에서는 문장을 읽지 못하므로, 검색어로 추천받고 클립보드 복사로 넣습니다.
3. 창이 열리기 **전에**, macOS 손쉬운 사용 기능으로 입력칸의 글을 읽고, 그중 커서 주변 문장을 **최대 140글자**로 잘라 냅니다.
   - 140글자는 읽는 범위가 아닙니다. **화면에 보여 주고 TypeSafe에 보내는 문장 길이의 상한**입니다. 실제로 읽는 범위는 아래 "API 키와 개인정보"를 보세요.
   - 글자를 드래그해 선택해 두었다면 선택한 글을 140글자 이내로 잘라 씁니다.
   - 커서 앞 글을 먼저 담고, 남는 자리에 커서 뒤의 같은 문장을 채웁니다.
4. 잘라 낸 문장을 TypeSafe API로 보내 JEV에게 "이 문장에 가장 어울리는 이모지는?"을 묻습니다.
   JEV는 후보 232개 각각의 확률을 돌려주고, 앱은 확률이 높은 순서로 **10개**를 보여 줍니다.
5. 이모지를 클릭하거나 ⌘1~⌘0을 누르면 창이 닫히고 **원래 입력칸의 커서 위치에** 이모지가 들어갑니다.
   넣기 직전에 두 번 확인합니다: 같은 앱인지, 같은 입력칸인지, 커서 위치와 선택한 글이 그대로인지,
   글을 쓸 수 있는 칸인지, 비밀번호 칸이 아닌지. 처음에 커서 주변 문장을 읽지 못한 입력칸도 자동으로 넣지 않습니다.
   하나라도 맞지 않으면 이모지를 클립보드에 복사한 뒤 이유와 ⌘V 안내를 보여 줍니다.
   넣은 뒤에는 입력칸을 다시 읽어 이모지가 실제로 들어갔는지 확인합니다. 확인되지 않으면 "들어갔는지 확인하지 못했어요"와 ⌘V 안내를 보여 줍니다.

검색창에 단어(예: `축하`, `피곤해`, `coffee`)를 넣고 Return을 눌러도 같은 방식으로 10개를 추천합니다.

```
⌥⌘E ─▶ 입력칸 글 읽기 ─▶ 커서 주변 문장 140자로 자르기 ─▶ 작은 창 열기 ─▶ JEV에 질문 ─▶ 10개 표시 ─▶ 클릭 ─▶ 확인 후 원래 입력칸에 입력
            │ 읽지 못하면                                                   │ 실패하면              │ 확인이 안 되면
            ▼                                                               ▼                       ▼
   이유 + 다음 행동 + 검색어 입력                    이유 + 다음 행동 + 버튼(설정 열기, 다시 시도)    클립보드에 복사 + ⌘V 안내
```

## Claude 데스크톱 앱으로 직접 빌드하기 (터미널 입력 없음)

터미널에 명령을 직접 입력할 필요가 없습니다. Claude가 대신 빌드합니다.

1. 이 저장소를 내려받습니다. GitHub 페이지의 초록색 **Code** 버튼 > **Download ZIP**을 누르고, 받은 ZIP을 더블클릭해 폴더를 풉니다.
2. **Claude 데스크톱 앱**을 열고 **Code** 탭으로 갑니다.
3. 폴더 선택 버튼을 눌러 방금 푼 `jev-emoji-claude-lesson` 폴더를 고릅니다.
4. 채팅 창에 이렇게 적습니다.

   > 맥 앱으로 빌드해 줘

5. Claude가 명령을 실행해도 되는지 물으면 내용을 읽고 허용합니다. 빌드에는 몇 분 걸립니다.
6. 끝나면 `build` 폴더에 **JEV Emoji.app**이 생깁니다. "Finder에서 보여 줘"라고 하면 위치를 열어 줍니다.

> Claude가 빌드할 때 쓰는 파일은 `scripts/build-app.sh`입니다. 빌드에는 Mac에 Xcode 또는 Command Line Tools가 있어야 합니다. 없으면 Claude가 설치 방법을 안내합니다.

## 미리 빌드된 ZIP으로 써 보기

저장소의 **Releases**에 `JEV-Emoji-0.1.0-dev-preview-macOS14-arm64.zip`을 올릴 예정입니다.
ZIP에는 앱만 들어 있고, **API 키는 들어 있지 않습니다**. 키는 처음 실행한 뒤 설정 창에서 직접 넣습니다.

### 처음 열 때 (공증 안 된 앱)

1. ZIP을 더블클릭해 풀고, **JEV Emoji.app**을 `응용 프로그램` 폴더로 옮깁니다.
2. 앱을 더블클릭합니다. "열 수 없습니다" 경고가 나오면 **완료**를 누릅니다.
3. **시스템 설정 > 개인정보 보호 및 보안**으로 가서 아래쪽의 **그래도 열기**를 누르고 한 번 더 확인합니다.
4. 이후에는 평소처럼 열 수 있습니다.

### 처음 실행했을 때 할 일

1. **API 키 저장**: 키가 없으면 설정 창이 자동으로 열립니다. 키를 붙여 넣고 `키체인에 저장`을 누릅니다.
2. **손쉬운 사용 권한 켜기**: 설정 창의 `시스템 설정 열기`를 누르고, 시스템 설정 > 개인정보 보호 및 보안 > 손쉬운 사용에서 **JEV Emoji**를 켭니다.
   이 권한이 있어야 다른 앱의 커서 주변 글을 읽고, 이모지를 원래 입력칸에 넣을 수 있습니다.

## 문제가 생기면 (앱이 보여 주는 안내)

앱은 오류를 그대로 보여 주지 않고 **무엇이 문제인지, 왜 그런지, 다음에 무엇을 하면 되는지**를 함께 보여 줍니다.

| 상황 | 이유 | 다음 행동 (창의 버튼) |
| --- | --- | --- |
| 손쉬운 사용 권한 없음 | 다른 앱의 글을 읽을 수 없음 | `손쉬운 사용 설정 열기`, `검색어 입력하기` |
| 입력칸을 못 찾음 | 커서가 입력칸에 없음 | 입력칸 클릭 후 다시 ⌥⌘E, 또는 검색어 입력 |
| 비밀번호 칸 | 보안 입력칸은 읽지 않음 | 검색어 입력 |
| 앱이 글을 알려 주지 않음 | 일부 브라우저, Electron 앱 | 검색어를 입력해 추천받기. 이모지를 고르면 자동으로 넣지 않고 클립보드에 복사하니, 원래 입력칸을 클릭하고 ⌘V |
| 입력칸이 비어 있음 | 읽을 문장이 없음 | 문장을 쓰고 다시 시도, 또는 검색어 입력 |
| 앱이 응답하지 않음 | 0.4초 안에 답이 없음 | 잠시 뒤 다시 시도, 또는 검색어 입력 |
| API 키 없음 / 틀림 (401) | 키가 없거나 거부됨 | `API 키 설정 열기` |
| 요청이 많음 (429), 서버 바쁨 (529) | 자동으로 2번 다시 시도한 뒤에도 실패 | `다시 시도` |
| 인터넷 끊김, 시간 초과 | 네트워크 문제 | 네트워크 확인 후 `다시 시도` |

권한이 없거나, 커서 주변 문장을 읽지 못했거나, 글을 쓸 수 있는 칸인지 확인할 수 없거나, 그 사이 앱·입력칸·커서 위치가 바뀌었거나, 비밀번호 칸이면 이모지를 바로 넣지 않습니다. 대신 **클립보드에 복사**하고 이유와 "⌘V를 누르세요" 안내를 보여 줍니다.

JEV 응답에 확률이 없거나 형식이 이상하면(0보다 작거나 1보다 큰 확률, 확률 합이 1에서 0.05 넘게 벗어남, 모르는 이모지, 10개 미만 등) 기본 이모지를 보여 주지 않고 "응답을 이해하지 못했어요"와 다시 시도 버튼을 보여 줍니다.

## API 키와 개인정보

- 키는 설정 창에서 사용자가 직접 넣고, 맥의 **로그인 키체인**에 일반 암호 항목(서비스 이름 `local.jevemoji.typesafe`)으로만 저장합니다. 코드에서 iCloud 동기화 옵션은 켜지 않았습니다. 키체인 앱에서 이 항목을 확인하거나 지울 수 있습니다.
- 키는 코드, 설정 파일, 로그 어디에도 들어가지 않습니다. 앱은 로그를 남기지 않습니다.
- 저장한 키는 화면에 다시 보여 주지 않고 "저장된 키가 있어요"만 표시합니다.
- 요청할 때마다 키체인에서 읽어 `Authorization` 헤더에만 넣습니다.
- 서버가 보낸 오류 문장은 화면에 보여 주지 않고 오류 코드만 보여 줍니다. 그 문장에 키나 읽은 문장이 섞여 있을 수 있기 때문입니다.
- **이 앱은 입력칸의 글을 140글자보다 길게 읽을 수 있습니다.** macOS 손쉬운 사용 기능(접근성 API)으로 읽는 범위는 다음과 같습니다.
  - 입력칸의 글이 약 4,000자 이하이면 입력칸 전체를 읽습니다.
  - 그보다 길면 커서 앞뒤 약 800자를 읽습니다. 앱이 일부만 읽기를 지원하지 않으면 입력칸 전체를 읽습니다.
  - 글을 드래그해 선택해 두었다면 선택한 글 전체를 읽습니다.
  - 이모지를 넣은 뒤 실제로 들어갔는지 확인할 때도 입력칸 내용을 다시 읽습니다.
  - 비밀번호 칸은 읽지 않습니다.
- 읽은 글은 커서 주변 문장을 고르고 입력을 확인하는 데에만 메모리에서 잠깐 쓰고, 파일이나 로그에 저장하지 않습니다.
- TypeSafe로 보내는 내용은 **잘라 낸 문장 최대 140글자(또는 검색어)와 이모지 후보 목록**뿐입니다. 화면에 보여 주는 문장도 같은 140글자입니다.
- 네트워크 응답은 디스크에 캐시하지 않습니다(ephemeral 세션).

## 알려진 한계

- 일부 웹 브라우저와 Electron 앱은 커서 주변 글을 macOS에 알려 주지 않습니다. 이때는 검색어로 추천받을 수 있지만, 이모지는 자동으로 넣지 않고 클립보드에 복사한 뒤 ⌘V 안내를 보여 줍니다.
- 앱을 다시 빌드하면 서명이 바뀌어 손쉬운 사용 권한을 다시 켜야 할 수 있습니다. 같은 이유로 키체인 접근 확인 창이 한 번 뜰 수 있습니다.
- JEV는 영어에서 가장 정확하고 한국어도 처리하지만 정확도는 조금 낮을 수 있다고 공식 문서에 적혀 있습니다. 그래서 후보마다 영어 뜻과 한국어 키워드를 함께 보냅니다.
- 이 미리보기는 빌드까지 확인했습니다. 자동 테스트와 실제 사용 확인은 아직 하지 않았습니다.
- Apple 공증을 받지 않아 처음 열 때 경고가 나옵니다. Intel Mac은 지원하지 않습니다.
